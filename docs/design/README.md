# Designs

Approved designs for registry pages, copied from the awml.io storyboard canvas. Each file is a
static mockup in the canvas's format: plain HTML with inline styles, a `<helmet>` block for fonts
and a small script block you can ignore. Example data in them (names, dates, tokens) is made up.

A design is the authority for its page's layout, placement and words. Build the page in the
registry's own components and `src/app/site.css`, not by pasting inline styles, and keep the
site's existing header. Where a design and the code disagree, follow the design and say so in
the pull request.

- `settings.html`: `/settings`
- `tokens.html`: `/settings/tokens`
